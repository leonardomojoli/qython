Política de assinatura de código (Code signing policy)

Versão 1 · 15 de novembro de 2026 · vale para os instaladores do Qython 1.3 em diante

  • Hoje os instaladores do Windows e do macOS não são assinados digitalmente. O Windows (SmartScreen) e o macOS (Gatekeeper) avisam na primeira abertura. No Linux não há aviso.
  • Todo instalador é construído a partir do código-fonte público deste projeto, por um fluxo automático no GitHub, e você pode conferir o arquivo que baixou (seção 2).
  • Quando houver assinatura, ela seguirá as regras das seções 3 e 4, e esta página será atualizada.

1. De onde vêm os instaladores

Os instaladores (Windows .exe, macOS .dmg e .zip, Linux .deb e AppImage) e o aplicativo Android (.apk) só são publicados na página de versões do projeto no GitHub. Cada um é construído a partir do código-fonte público, no GitHub Actions, quando uma versão é marcada. O roteiro do build está no repositório, em desktop-release.yml e release.yml. Não há outro lugar oficial para baixar o Qython: arquivo de qualquer outro endereço não é do projeto.

2. Como conferir um download

A página de cada versão mostra, ao lado de cada arquivo, o seu SHA-256 (a coluna Digest). Calcule o do arquivo que você baixou e compare:

  • Linux: sha256sum Qython-*.deb
  • macOS: shasum -a 256 Qython-*.dmg
  • Windows (PowerShell): Get-FileHash .\Qython-*-win-x64.exe -Algorithm SHA256

Se os valores forem diferentes, não abra o arquivo: baixe de novo e, se continuar diferente, avise em relato privado.

3. Quem decide o que é publicado

O Qython é mantido por uma pessoa, Leonardo de Abreu (github.com/leonardomojoli), que escreve o código, revisa e aprova cada versão. O projeto não aceita contribuições de outras pessoas no código (veja o CONTRIBUTING.md), então nenhuma alteração entra numa versão sem passar por essa mesma pessoa.

4. Regras da assinatura de código

Quando os instaladores forem assinados, valem estas regras:

  • Só se assina o que foi construído a partir do código-fonte deste repositório, pelo fluxo automático. Nenhum arquivo feito à mão é assinado.
  • Cada versão assinada exige aprovação manual do mantenedor antes da assinatura.
  • O nome do produto é Qython e a versão é a mesma em todos os arquivos da versão.
  • A chave privada de assinatura não fica em computador do projeto, e o nome de quem assina é mostrado nesta página.
  • Componentes e modelos de terceiros que vêm junto (por exemplo, os modelos de IA) mantêm a licença e a autoria originais, como diz o arquivo NOTICE.

5. Privacidade e instalação

O Qython não tem telemetria. As conexões que o programa faz estão listadas na política de privacidade. A consulta periódica por versão nova (ao GitHub, no Windows, no macOS e no AppImage) você desliga em Ajuda → Procurar atualizações automaticamente; o .deb nunca faz essa consulta. O instalador do Windows instala só para o seu usuário, tem desinstalador, e nunca apaga os dados dos pacientes ao desinstalar.

6. Problemas

Se você achar que um arquivo publicado foi adulterado ou que o programa faz algo que esta página não descreve, abra um relato privado.

O Qython é software livre sob a licença AGPL-3.0 e uma ferramenta de apoio ao estudo e à documentação. Não é dispositivo médico e não substitui o julgamento clínico.
